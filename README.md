# Портфолио Axilium

Статический сайт с описанием проектов и демонстрационными страницами.

- Главная: `index.html`
- Стили главной: `styles.css`
- Демонстрационный лендинг: `demos/shawarma/`
- Демонстрация учёта посещаемости: `demos/attendance/`
- Статическое демо MealHub: `demos/mealhub/`
- Лендинг модульной мебели FORMA: `demos/forma/`

Демо «Шавермы» использует вымышленный бренд и адреса. Его форма работает локально в браузере и не отправляет введённые данные на сервер.

Демо MealHub использует оригинальные шаблоны и стили интерфейсов пользователя, повара и администратора с вымышленными данными. Навигация переключает разделы экранов; сервер и база данных не подключены. Исходный код Django находится в отдельном [репозитории](https://github.com/Axilium1749/mealhub-demo).

Демо посещаемости использует только вымышленные данные. Отметки хранятся в памяти вкладки и сбрасываются после обновления страницы. Рабочие API и база данных к нему не подключены.

Публикация рассчитана на GitHub Pages в репозитории `Axilium1749/axilium1749.github.io`.

FORMA — статичный демонстрационный furniture landing с локальным конфигуратором: три компоновки, четыре ткани, плавная смена 12 изображений и расчёт цены. Бренд, товары, характеристики и цены вымышлены. Форма ничего не отправляет и не сохраняет. Изображения созданы для демо и хранятся локально в WebP; сведения о создании и замене — в `demos/forma/assets/README.md`. Сборка и сторонние библиотеки для работы страницы не нужны.

Проверка FORMA: `node tools/test-forma.mjs` (нужен Playwright, путь к установленному Chrome можно задать через `CHROME_PATH`). Тест запускает локальный сервер, проверяет RU/EN, 12 состояний, адаптивность, клавиатуру, форму и ошибки загрузки. Скриншоты сохраняются во временную папку или в `FORMA_SCREENSHOTS`; флаг `--previews` обновляет изображения карточки на главной.

## Языки

На главной можно выбрать RU или EN. При первом посещении язык берётся из основного языка браузера: русский для `ru`, английский для остальных. Выбор хранится в `localStorage` под ключом `axilium-language` и действует на все демо на том же домене. В демо собственного переключателя нет.

Русские строки остаются в HTML и JavaScript как исходный текст. Английский словарь находится в `tools/en-dictionary.json`, дополнительные строки для динамических элементов — в `tools/i18n-runtime.template.js`. После изменения переводов выполните `node tools/build-i18n.mjs`, чтобы обновить подключаемый `i18n.js`. Проверка страниц в фоновом Chrome: `node tools/test-i18n.mjs`.

На главной английские скриншоты карточек лежат в `assets/*-preview-en.png` и подключаются через `data-preview-en` у соответствующих изображений.
