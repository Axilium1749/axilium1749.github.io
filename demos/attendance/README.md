# Демо учёта посещаемости

Публичный прототип мобильного интерфейса. Группы, имена и даты рождения вымышлены. Отметки хранятся только в памяти вкладки и сбрасываются при обновлении страницы. Демо не подключается к рабочему API и не использует базу данных.

На широком экране интерфейс остаётся шириной не более 430 px и расположен по центру.
