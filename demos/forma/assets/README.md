# FORMA image assets

All furniture and interiors are fictional images created with the built-in imagegen tool for this portfolio demo. They are illustrative, not measured product photography or evidence of a real product, fabric test, warranty or manufacturing process.

The 12 `compact|classic|corner` × `sand|moss|graphite|clay` WebP files are independent static images. Paths, dimensions and prices are mapped in `../script.js`; replace paths there when using real photography. No WebGL, runtime recolouring, remote image host or image API is involved. The studio images use the same reference to preserve camera, seams and lighting; small generative differences remain. Colour reproduction is indicative.

Product files are 1200 × 800, hero 1536 × 1024 with an 800px responsive variant; secondary editorial imagery is lazy loaded. WebP compression is quality 82 (hero mobile 80). `swatch-texture.webp` is a small crop of the generated fabric macro. The favicon is an original simple vector mark. Fonts use local system Arial and Georgia, with no external font requests.
